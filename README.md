# 📖 Учебный проект: Гостевая книга (Guest Book)

Данный проект является результатом практической части курса **“PHP 8. От теории к практике”** (автор: Андрей Кудлай). В рамках этого приложения реализован основной функционал взаимодействия пользователя с веб-интерфейсом, работа с базой данных и администрирование контента.

## 🎯 Основные возможности

В ходе разработки были реализованы следующие функции:

*   **Система пользователей:** Регистрация и авторизация.
*   **Работа с сообщениями:** Добавление новых записей (для авторизованных пользователей).
*   **Модерация:** Возможность изменения статуса сообщений и их редактирование (функции администратора).
*   **Валидация:** Проверка входных данных с помощью библиотеки `Valitron`.
*   **Пагинация:** Постраничный вывод сообщений.
*   **Безопасность:** Обработка данных форм, использование сессий, работа с PDO для защиты от SQL-инъекций.

## 🛠 Технологический стек

*   **Язык:** PHP 8.4
*   **База данных:** MySQL 8.4
*   **Сервер:** Apache 2.4
*   **Управление зависимостями:** Composer
*   **Среда разработки:** Docker & Docker Compose

## 🚀 Запуск проекта

Для запуска проекта вам потребуется установленный **Docker** и **Docker Compose**.

### Быстрый старт

1.  **Сборка и запуск контейнеров:**
    ```bash
    make up
    ```
2.  **Установка зависимостей (через Composer в контейнере):**
    ```bash
    make composer-install
    ```
3.  **Остановка проекта:**
    ```bash
    make down
    ```

### 🔗 Доступные URL

*   **Веб-интерфейс:** [http://localhost](http://localhost)
*   **phpMyAdmin:** [http://localhost:8080](http://localhost:8080) — управление базой данных MySQL.
*   **MySQL:** `localhost:3306`

## 📁 Структура проекта

*   `src/public/` — Основная директория с исходным кодом.
    *   `includes/` — Логика приложения: функции, работа с БД (`db.php`), класс пагинации.
    *   `views/` — Шаблоны отображения (TPL-файлы).
*   `config/` — Конфигурационные файлы Apache (`httpd.conf`) и PHP (`php.ini`).
*   `docker/` — Dockerfile для сборки PHP-контейнера.
*   `env/` — Переменные окружения (`.env`).
*   `Makefile` — Удобные команды для управления проектом.

## 🛠 Основные команды (Makefile)

*   `make up` — Запустить проект.
*   `make down` — Остановить и удалить контейнеры.
*   `make restart` — Перезапустить сервисы.
*   `make logs` — Просмотр логов всех сервисов.
*   `make status` — Проверить статус контейнеров.
*   `make shell-php` — Доступ к терминалу PHP-контейнера.
*   `make composer-install` — Установка PHP-пакетов.
